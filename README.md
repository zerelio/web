# Zerelio Web

Marketing website for [Zerelio](https://zerelio.com) — a Next.js 16 + Tailwind CSS 4 static site, no backend required.

## Stack

- **Next.js 16** — React framework with static export
- **Tailwind CSS 4** — utility-first styling

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs a fully static site — no backend or API needed.
